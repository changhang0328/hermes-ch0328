# 杜邦分析法（DuPont Analysis）

通过拆解净资产收益率（ROE），从三个维度评估一家上市公司的投资价值。

## 核心公式

```
净资产收益率 (ROE) = 销售净利率 × 总资产周转率 × 权益乘数
```

三大子公式：

```
销售净利率     = 净利润 ÷ 营业收入          （反映盈利能力）
总资产周转率   = 营业收入 ÷ 总资产          （反映运营效率）
权益乘数       = 总资产 ÷ 所有者权益合计      （反映财务杠杆）
```

三种典型企业盈利模式：

- **高利型**（如贵州茅台）：销售净利率远高于行业均值，靠产品溢价和品牌壁垒盈利
- **苦力周转型**（如永辉超市）：薄利多销，资产周转率极高，靠规模效率盈利
- **高杠杆型**（如万科A、招商银行）：权益乘数远高于行业均值，靠财务杠杆放大收益

## 可用工具

| 工具名 | 用途 | 必填参数 |
|--------|------|---------|
| `ragflow_retrieve` | 从金融知识库检索财务科目数据 | `question`（字符串） |
| `calc_eval` | 精确数学计算（Decimal 精度） | `expression`（字符串） |

### ragflow_retrieve 返回结构

成功时返回：
```json
{
  "question": "比亚迪 2024年 营业收入",
  "chunk_count": 3,
  "chunks": [
    {
      "content": "2024年比亚迪实现营业收入6023.15亿元...",
      "document_keyword": "比亚迪_2024年报.pdf",
      "similarity": 0.87
    }
  ]
}
```
失败时返回（包含 `error` 字段）：
```json
{ "error": "...", "kind": "..." }
```

### calc_eval 返回结构

成功时返回：
```json
{
  "expression": "12500 / 602315",
  "result": "0.020753",
  "precision": 28
}
```
失败时返回（包含 `error` 字段）。

## 严禁行为（关键规则）

1. **严禁心算任何数学运算** — 所有四则运算、百分比、乘法必须通过 `calc_eval` 完成
2. **严禁编造财务数据** — 只能使用 `ragflow_retrieve` 返回的真实数据
3. **熔断机制** — 4 个基础科目中任何一项未检索到数据（chunk_count=0 或返回 error），必须立即中止分析
4. **单位必须显式处理** — 中文财报中常见单位：`万元`（×10000）、`亿元`（×100000000）、`千元`（×1000）。分子分母同单位时比值与单位无关，可跳过换算
5. **查询必须精确** — 每次 `ragflow_retrieve` 的 `question` 中必须显式包含公司全称或简称 + 四位数年份（如"比亚迪 2024年 营业收入"），严禁模糊查询
6. **calc_eval 不传字符串** — expression 参数中只能出现数字和运算符，不得包含单位文字

## 工作流程

### 第0步：校验输入

确认已从用户处获取：
- 公司名称（全称或常用简称）
- 四位数年份

若缺失其中任何一项，向用户提出反问：
> 请提供需要分析的**公司名称**（全称或简称）和**年份**（四位数，如 2024）。

### 第1步：检索四个基础财务科目

依次调用 `ragflow_retrieve`，每个科目一次，**company** 和 **year** 为实际值：

**① 营业收入**
```
ragflow_retrieve(question="{company} {year}年 营业收入")
```

**② 净利润**
```
ragflow_retrieve(question="{company} {year}年 净利润")
```

**③ 总资产（资产总计）**
```
ragflow_retrieve(question="{company} {year}年 总资产 资产总计")
```

**④ 所有者权益合计**
```
ragflow_retrieve(question="{company} {year}年 所有者权益合计 股东权益合计")
```

以"比亚迪 2024年"为例，实际调用为：
```
ragflow_retrieve(question="比亚迪 2024年 营业收入")
ragflow_retrieve(question="比亚迪 2024年 净利润")
ragflow_retrieve(question="比亚迪 2024年 总资产 资产总计")
ragflow_retrieve(question="比亚迪 2024年 所有者权益合计")
```

### 第2步：熔断检查（关键拦截点）

逐一检查上面 4 次检索的返回结果：

- 若某次返回的 `chunk_count == 0` → **中止**，该科目未检索到
- 若某次返回中包含 `error` 字段 → **中止**，检索失败
- 若某次返回的 chunks[].content 中无法提取到明确的数值 → **中止**

**中止提示模板**（替换大括号内容为实际值）：
> 抱歉，未能在知识库中检索到 **{company}** {year} 年的 **{缺失科目}** 数据，无法为您生成准确的杜邦分析报告。建议确认该公司该年度的财务报表是否已收录至知识库，或尝试其他年份。

其中 `{缺失科目}` 为：营业收入 / 净利润 / 总资产 / 所有者权益合计 之一。

**只有四项全部就绪才能进入第3步。**

### 第3步：提取数值 & 单位处理

从每次成功的检索中，读取 top chunk 的 `content` 字段，提取数值和单位。

示例：
- content 中写道："2024年比亚迪实现营业收入6023.15亿元"
- 提取：营业收入 = 6023.15，单位 = 亿元

**单位换算规则：**
- 若分子分母的单位相同（如均为"亿元"），比值与单位无关，直接传原始数字给 calc_eval
- 若单位不同，必须先统一换算为同一基准（建议统一为纯数字，如 6023.15 亿元 → 602315000000）

### 第4步：调用 calc_eval 进行精确计算

依次调用 `calc_eval`，**严禁心算**。

**计算 ① — 销售净利率**
```
calc_eval(expression="{净利润数值} / {营业收入数值}")
```
例：`calc_eval(expression="1250 / 6023.15")`（假设单位均为"亿元"，比值不变）

**计算 ② — 总资产周转率**
```
calc_eval(expression="{营业收入数值} / {总资产数值}")
```

**计算 ③ — 权益乘数**
```
calc_eval(expression="{总资产数值} / {所有者权益数值}")
```

**计算 ④ — ROE**

使用上面 3 个 calc_eval 返回的 `result` 值进行计算：
```
calc_eval(expression="{净利率结果} * {周转率结果} * {权益乘数结果}")
```

### 第5步：生成结构化 Markdown 报告

#### 5.1 标题

```
# {company} {year}年 杜邦分析报告
```

#### 5.2 基础科目数据表

| 财务指标 | 数值 | 单位 | 数据来源 |
|---------|------|------|---------|
| 营业收入 | {值} | {单位} | ragflow_retrieve |
| 净利润 | {值} | {单位} | ragflow_retrieve |
| 总资产 | {值} | {单位} | ragflow_retrieve |
| 所有者权益合计 | {值} | {单位} | ragflow_retrieve |

#### 5.3 三大效率指标

| 指标 | 公式 | 计算结果 |
|------|------|----------|
| 销售净利率 | 净利润 / 营业收入 | {结果}% |
| 总资产周转率 | 营业收入 / 总资产 | {结果} |
| 权益乘数 | 总资产 / 所有者权益 | {结果} |

百分比需将 calc_eval 返回的小数乘以 100（如 0.0523 → 5.23%）。

#### 5.4 净资产收益率（ROE）

```
## 净资产收益率 (ROE)

**ROE = 销售净利率 × 总资产周转率 × 权益乘数 = {ROE结果}%**
```

简短点评：ROE 偏高/偏低，主要驱动因素是什么。

#### 5.5 企业盈利模式判定

根据三项指标的特征判定：

| 企业类型 | 特征 | 典型行业 |
|---------|------|---------|
| 高利型 | 销售净利率远高于行业均值（通常 >20%） | 白酒、医药、软件 |
| 苦力周转型 | 总资产周转率远高于行业均值（通常 >1.5） | 商超、物流 |
| 高杠杆型 | 权益乘数远高于行业均值（通常 >3） | 房地产、金融 |

```
## 企业盈利模式判定

**类型：{高利型 / 苦力周转型 / 高杠杆型 / 混合型}**

{简要说明判定依据，结合三项指标的相对强弱进行分析}
```

#### 5.6 报告尾注

```

```

## 常见错误（不要做的事）

- ❌ 跳过 `calc_eval` 在脑海中计算比例
- ❌ 某项科目未检索到数据仍继续分析
- ❌ 猜测或插值补全缺失数据
- ❌ calc_eval 的 expression 中包含单位文字（如"6023.15亿元 / 100亿元"）
- ❌ ragflow_retrieve 的 question 中省略年份或使用模糊描述
- ❌ 混淆"总资产"与"净资产"——总资产 = 资产总计，净资产 = 所有者权益合计
- ❌ 将 calc_eval 返回的小数直接当作百分比显示（0.0523 ≠ 5.23，需要 ×100 才是 5.23%）

## 故障排查

- **所有 4 次查询均返回 chunk_count=0**：该公司或该年份可能不在知识库中，建议用户确认公司名称/年份格式是否正确
- **部分查询返回 chunks 但 content 中无数值**：chunks 内容可能是文字描述而非数据，建议用户确认该科目是否以不同名称呈现（如"营收"vs"营业收入"）
- **calc_eval 报 division_by_zero**：某科目数值为 0，属于异常财务数据，应在报告中特别标注并停止分析
